## E. Accounts and keys needed later

Never paste these into chat. They go into `.env` (see `docs/setup-and-deployment.md`):

- MongoDB Atlas connection string (the `oedf-dev` database is used for development)
- Cloudinary cloud name, API key and API secret
- Brevo SMTP login and key, and a verified sender (entered by the owner in `.env` and Vercel)
